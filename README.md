# 健康记录卡

一个纯静态、离线优先的手机健康记录表单。

- 所有填写内容只保留在浏览器本地草稿中
- 不上传体重、饮食、睡眠、训练或图片到网站服务器
- 点击“生成记录并复制”后，生成可直接粘贴到微信健康小克的结构化文本
- 睡眠、运动、饮食原始图片请直接用微信发送，保留清晰度与信息完整性

## 使用

1. 打开网页并填写当天记录。
2. 点击“生成记录并复制”。
3. 打开微信，粘贴文本给健康小克。
4. 有手表睡眠、运动或食物照片时，直接另发原图。

## 隐私

GitHub Pages 上的网页仅托管 HTML/CSS/JavaScript 程序，不包含任何真实健康台账、图片、账号凭证或个人记录。
